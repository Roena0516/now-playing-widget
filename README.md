# Pear Now Playing

Pear Now Playing은 [Pear Desktop](https://github.com/pear-devs/pear-desktop)(YouTube Music 데스크톱 앱)에서 재생 중인 곡을 화면 위에 표시하는 Windows 오버레이 위젯입니다.
곡이 바뀌면 화면 구석에 앨범 아트, 제목, 아티스트, 진행 바가 몇 초 동안 나타납니다.
싱크 가사가 있는 곡이라면 YouTube Music 모바일 앱처럼 부드럽게 스크롤되는 가사 카드도 함께 표시합니다.

  <img src="docs/lyrics-scroll.gif" alt="가사 스크롤 미리보기" width="460">
</p>

- 전체 화면 게임, 영상, 작업 중인 창 등 어떤 화면 위에도 표시됩니다. 특히 테두리 없는 창 모드로 실행한 게임에서 사용하기에 적합합니다.
- 클릭과 키 입력은 위젯 아래에 있는 창으로 그대로 전달됩니다. 위젯이 포커스를 가져가지 않습니다.
- 전역 단축키로 이전 곡, 다음 곡, 재생/일시정지를 조작할 수 있습니다.
- Windows 10/11에 기본으로 설치되어 있는 .NET Framework 4.8에서 실행되므로 따로 설치할 프로그램이 없습니다.

디자인은 [carol-web](https://github.com/team-carol/carol-web)의 디자인 시스템(색 토큰, Pretendard 계열 폰트, 16px 둥근 카드, 1px 테두리, 3px 강조선)을 따릅니다.

## 기능

| | |
|---|---|
| **곡 카드** | 앨범 아트, 제목, 아티스트·앨범, 진행 바를 표시합니다. 곡이 바뀌거나 일시정지/재생할 때 잠시 나타났다가 사라지며, 계속 표시하도록 설정할 수도 있습니다. |
| **싱크 가사** | YouTube Music 가사를 먼저 찾고, 찾지 못하면 [LRCLIB](https://lrclib.net)에서 찾습니다. 찾은 가사는 곡 카드 아래에 붙여서 표시합니다. |
| **긴 제목 스크롤** | 제목이 카드보다 길면 전광판처럼 옆으로 흘러가며 표시됩니다. |
| **일본어 폰트** | 한국어, 영어, 일본어를 Pretendard JP 폰트 하나로 표시합니다. |
| **단축키** | 다시 보기, 재생/일시정지, 다음/이전 곡, 계속 표시, 가사 켜기/끄기를 지원합니다. |

## macOS 버전

macOS 13 이상에서는 Swift/AppKit으로 만든 macOS 버전을 사용할 수 있습니다. [Releases](../../releases)에서 macOS용 DMG 파일(`PearNowPlaying-macOS`로 시작하는 `.dmg` 파일)을 내려받아 열고, 창에 보이는 `Pear Now Playing.app`을 `Applications` 폴더로 끌어다 놓은 뒤 실행합니다.
macOS 버전도 곡 카드, 싱크 가사, 메뉴 막대 제어, 전역 단축키를 지원하며, 가사를 찾는 순서는 Windows 버전과 같습니다.
이 앱은 Apple의 공증을 받지 않았기 때문에 처음 실행할 때 열리지 않을 수 있습니다. 그러면 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기**를 누릅니다. 빌드 방법과 설정은 [macOS 안내](macos/README.md)에 정리되어 있습니다.

## 설치

### 1. Pear Desktop 설정 (처음 한 번만 합니다)

1. Pear Desktop 메뉴에서 **플러그인 → API 서버 [베타]** 를 켭니다.
2. (권장) 같은 메뉴에 있는 **호스트 명**을 `0.0.0.0`에서 `127.0.0.1`로 바꿉니다.
   호스트 명이 `0.0.0.0`이면 같은 네트워크에 있는 다른 기기도 API 서버에 접속을 시도할 수 있습니다.
3. **포트**는 기본값인 `26538`을 그대로 두면 됩니다. 포트를 바꿨다면 위젯 설정 파일의 `port`도 같은 값으로 바꿉니다.
4. **인증 정책**은 기본값(첫 번째 요청 시 인증)을 그대로 두면 됩니다.

### 2. 실행

1. [Releases](../../releases)에서 Windows용 zip 파일(`PearNowPlaying-Windows`로 시작하는 `.zip` 파일)을 내려받아 압축을 풀고 `PearNowPlaying.exe`를 실행합니다.
   실행하면 작업 표시줄 오른쪽 트레이에 음표 아이콘이 나타납니다.
2. Pear Desktop에 **"pear-now-playing ... API에 액세스하도록 허용하시겠습니까?"** 창이 나타나면 **허용**을 누릅니다. 이 확인 창은 처음 한 번만 나타납니다.
3. 노래를 재생하면 화면 왼쪽 아래에 곡 정보가 나타납니다.

> 이 프로그램은 코드 서명이 되어 있지 않으므로, 처음 실행할 때 "Windows의 PC 보호" 창이 나타날 수 있습니다. 그러면 **추가 정보 → 실행**을 누릅니다.

Windows를 시작할 때 자동으로 실행하려면 `Win + R`로 `shell:startup` 폴더를 열고, 그 폴더에 exe 바로 가기를 넣습니다.

## 단축키

| 단축키 | 기능 |
|---|---|
| `Ctrl + Alt + ↑` | 지금 곡 다시 보기 |
| `Ctrl + Alt + ↓` | 재생 / 일시정지 |
| `Ctrl + Alt + →` | 다음 곡 |
| `Ctrl + Alt + ←` | 이전 곡 |
| `Ctrl + Alt + P` | 곡 정보 계속 표시 켜기/끄기 |
| `Ctrl + Alt + L` | 가사 표시 켜기/끄기 |

단축키는 다른 앱을 사용하는 중에도 동작합니다. 다른 키 조합을 사용하려면 설정 파일에서 변경합니다.

## 가사

- 곡이 바뀌면 다음 두 곳에서 싱크 가사를 찾습니다. 두 곳 모두 Pear Desktop의 가사 플러그인이 사용하는 곳입니다.
  1. **YouTube Music**: YouTube Music 앱에 표시되는 가사입니다. Pear의 YTMusic 가사 제공자와 같은 방식으로 가져옵니다(아래 "통신하는 곳"을 참고합니다).
  2. **[LRCLIB](https://lrclib.net)**: YouTube Music에서 가사를 찾지 못했거나 요청이 실패하면 이 공개 가사 데이터베이스에서 찾습니다. 곡을 대조하는 방식도 Pear와 같습니다.
- **커버곡(歌ってみた 등)**: 개인이 올린 영상에는 YouTube Music 가사가 없는 경우가 많습니다. 이때는 영상 설명란에 있는 원곡 링크를 찾아서 **원곡의 싱크 가사**를 대신 표시합니다. 歌ってみた 영상은 보통 원곡 반주를 그대로 사용하므로 가사 타이밍이 잘 맞습니다.
  - "原曲 / 本家 / original / 원곡" 같은 표시가 붙은 링크를 먼저 확인하고, Mix·Off Vocal·일러스트 링크는 건너뜁니다.
  - 제목에 remix, arrange, アレンジ, 편곡, acoustic, 弾き語り, piano ver, short ver 같은 단어가 있으면 음악이 원곡과 달라진 것이므로 원곡 가사를 사용하지 않습니다.
  - 원곡과 커버의 길이가 10초 넘게 차이 나는 경우(인트로를 자르거나 편곡한 경우)에도 원곡 가사를 사용하지 않습니다.
  - 설명란에 원곡 링크가 없으면 영상 제목에서 곡 이름과 원곡자를 읽어 LRCLIB에서 원곡을 찾습니다. 예를 들어 `ワールドイズマイン / ryo(covered by …)`라는 제목에서는 "ワールドイズマイン"과 "ryo"를 읽습니다.
    제목에 원곡자가 없으면 설명란에 있는 "原曲：…", "作詞・作曲：…", "Music: …" 줄에서 원곡자를 읽습니다.
    원곡자를 알 수 없으면 곡 이름이 같고 길이 차이가 10초 이내인 곡을 고릅니다.
    (YouTube Music 검색은 로그인하지 않으면 공식 음원을 결과로 보여주지 않으므로 사용하지 않습니다.)
  - 원곡에 YouTube Music 가사가 없으면 원곡의 제목과 아티스트로 LRCLIB에서 찾습니다.
    이렇게 찾은 가사는 트레이의 가사 상태에 "(YouTube Music · 원곡)", "(LRCLIB · 원곡 검색)"처럼 출처가 표시됩니다.
- 곡이 재생되는 동안 Pear 재생목록에 있는 **다음 곡의 가사를 미리 찾아 둡니다**(곡이 시작되고 10초 뒤에 찾습니다). 따라서 다음 곡이 시작되면 가사가 바로 나타납니다.
  미리 찾을 때 가사를 찾지 못한 곡은 그 곡이 실제로 시작될 때 다시 찾습니다. 가사 서버가 바빠서 미리 찾기에 실패했다면, 지금 곡이 재생되는 동안 30초 뒤와 90초 뒤에 다시 시도합니다.
- LRCLIB에서 찾은 가사는 컴퓨터에 저장해 둡니다(`%LocalAppData%\PearNowPlaying\lyrics-cache`). 같은 곡을 다시 재생하면 LRCLIB에 묻지 않고 저장된 가사를 바로 표시합니다. 저장한 지 90일이 지난 가사는 다시 찾고, 저장된 곡이 3,000곡을 넘으면 오래된 것부터 지웁니다. 저장된 가사가 잘못되었다면 트레이 메뉴의 **가사 다시 찾기**를 누릅니다. 그러면 저장된 가사를 지우고 새로 찾습니다.
- YouTube Music 가사 중계 서버에 보낸 요청이 3번 연달아 실패하면, 그 뒤 10분 동안은 LRCLIB에서만 가사를 찾습니다. **가사 다시 찾기**를 누르면 이 대기 시간과 관계없이 바로 다시 시도합니다.
- 아티스트 표기가 다르더라도(`Mikito-P`와 `みきとP`처럼) 제목이 같고 곡 길이 차이가 3초 이내이면 같은 곡으로 판단합니다.
- LRCLIB는 무료로 운영되는 서버이므로 사용자가 몰리면 일시적으로 "바쁨"(503) 응답을 보냅니다. 이 응답을 받으면 2초 뒤에 같은 요청을 한 번 더 보냅니다.
  그래도 실패하면 15초 뒤와 45초 뒤에 처음부터 다시 찾습니다. 그래도 가사가 나타나지 않으면 트레이 메뉴의 **가사 다시 찾기**를 누릅니다.
  다시 찾는 동안에는 진행 상황이, 검색이 끝나면 결과가 화면에 잠시 표시됩니다.
- 가사를 찾으면 **곡 카드 바로 아래**에 가사 카드가 붙어서 계속 표시됩니다. 두 카드는 너비가 같으므로 하나의 카드처럼 보입니다.
- 이전 줄, 지금 줄, 다음 줄이 하나의 목록으로 표시되며, 줄이 바뀌면 목록이 부드럽게 위로 스크롤됩니다.
  지금 줄은 밝게, 나머지 줄은 흐리게 표시되고, 목록의 위아래 끝으로 갈수록 점점 흐려집니다. 긴 줄은 최대 두 줄까지 줄바꿈하여 표시합니다.
- 곡 카드가 나타나거나 사라지면 가사 카드도 부드럽게 위치를 옮깁니다.
- 간주 구간에는 ♪가 표시됩니다. 일시정지하면 강조선이 회색으로 바뀝니다.
- 싱크 가사가 없는 곡(가사 데이터베이스에 없거나 시간 정보가 없는 가사만 있는 곡)에는 가사 카드를 표시하지 않습니다. 가사 상태는 트레이 메뉴의 맨 위에서 확인할 수 있습니다.
- 가사가 노래보다 빠르거나 늦게 표시되면 트레이 메뉴의 **가사 타이밍**에서 조정합니다.

> 영상 자막(YouTube 자막)을 가져오는 기능은 넣지 않았습니다. 자막을 가져오려면 공식적인 방법 없이 YouTube 내부 데이터를 수집해야 하는데, 이는 YouTube 약관에 어긋나기 때문입니다.

## 긴 곡 제목

제목이 카드 너비보다 길면 처음 1.8초 동안 제목의 앞부분을 보여준 뒤, 제목이 옆으로 천천히 이동합니다.
제목의 끝이 지나가면 제목의 앞부분이 뒤이어 들어오면서 계속 반복되고, 카드의 양쪽 끝에서는 글자가 부드럽게 흐려집니다.
제목이 카드 안에 모두 들어가면 제목은 움직이지 않습니다. 아티스트·앨범 줄은 길면 `…`로 줄여서 표시합니다.

## 앨범 곡 제목

YouTube Music은 곡 제목을 앱의 언어 설정에 맞춰 보여줍니다. 그래서 레이블이 번역 제목을 등록해 둔 앨범 곡은 원제 대신 번역 제목만 표시될 수 있습니다(예: `心を刺す言葉だけ`가 `Only Words`로 표시됨). 이런 곡은 YouTube Music의 재생목록 정보를 확인해서 **원제 - 번역** 형식(`心を刺す言葉だけ - Only Words`)으로 보여줍니다. 번역 제목이 없는 곡이나 이미 원제로 표시되는 곡은 그대로 둡니다. 곡이 시작된 직후에는 번역 제목이 잠시 보일 수 있으며, YouTube Music 응답을 받으면(보통 1초 안) 바뀝니다.

## 폰트

한국어, 영어, 일본어(가나와 상용 한자 약 7,100자)를 모두 **Pretendard JP** 폰트 하나로 표시합니다.
폰트에 없는 글자(희귀한 한자, 중국어 간체 등)가 들어 있는 줄만 Windows에 설치된 폰트(Yu Gothic, 맑은 고딕)로 표시합니다.

## 트레이 메뉴

트레이 아이콘을 마우스 오른쪽 버튼으로 클릭하면 메뉴가 나타납니다. 아이콘을 더블클릭하면 지금 재생 중인 곡이 표시됩니다.

- **지금 곡 보기**, **이전 곡 / 재생·일시정지 / 다음 곡**
- **위젯**: 곡 카드와 위젯의 표시 방법, 위치, 크기를 정합니다.
  - **곡 정보 계속 표시**: 곡 카드가 사라지지 않고 계속 표시되도록 합니다. 처음에는 켜져 있습니다. 이때 진행 바는 실시간으로 움직입니다.
  - **영상 곡 제목**: 앨범 곡이 아닌 영상(MV, 커버, 일반 업로드)에 표시할 제목을 고릅니다. **곡 제목**(기본값)은 YouTube Music이 정리한 곡 이름(예: `デビルじゃないもん`)을, **영상 제목**은 영상에 붙은 제목 그대로(예: `HIMEHINA『데빌이 아닌걸』Cover【일인이역】`)를 보여줍니다. 영상 제목은 Pear Desktop의 Discord 상태 표시와 같은 제목입니다.
  - **위치**: 화면의 여섯 곳 중 한 곳을 고르거나, 끌어서 옮겨 둔 **직접 옮긴 위치**를 고릅니다.
  - **모니터**: 모니터가 여러 대일 때 위젯을 표시할 모니터를 고릅니다. 메뉴를 열 때마다 연결된 모니터 목록을 새로 읽습니다.
  - **크기**: 작게 / 보통 / 크게 / 아주 크게 중에서 고릅니다.
  - **위젯 끌어서 옮기기**: 이 항목을 켜면 위젯을 마우스로 끌어서 원하는 곳(다른 모니터 포함)에 놓을 수 있습니다. 다 옮겼으면 이 항목을 다시 눌러 끝냅니다. 평소에는 위젯이 클릭을 아래 창으로 통과시키기 때문에, 이 항목이 켜져 있는 동안에만 위젯을 끌 수 있습니다. 위젯을 화면의 아래쪽 절반에 놓으면 아래쪽 위치처럼 가사 카드가 아래에 고정되고, 위쪽 절반에 놓으면 곡 카드가 위에 고정됩니다.
- **가사**: 가사 카드에 관한 설정입니다.
  - **가사 표시**: 가사 카드를 켜거나 끕니다. 처음에는 켜져 있습니다.
  - **앨범 곡만 가사 표시**: 이 항목을 켜면 앨범 곡(공식 음원)에서만 가사를 찾아 표시하고, MV·커버·일반 업로드 영상에서는 가사를 찾지 않습니다. 처음에는 꺼져 있습니다.
  - **가사 다시 찾기**: 지금 곡의 가사를 다시 검색합니다(저장된 가사도 지우고 새로 찾습니다).
  - **가사 타이밍**: 가사 타이밍을 1초 빠르게부터 1초 늦게까지 조정합니다.
- **Pear 연결 권한 다시 요청**: Pear Desktop의 허용 창에서 실수로 거부했을 때 사용합니다.
- **설정 파일 열기 / 설정 다시 불러오기 / 오류 기록 열기**
- **업데이트 확인 / 업데이트 설치**: 아래 "업데이트"를 참고합니다.

YouTube Music 가사를 먼저 찾는 동작은 메뉴에 없으며 항상 켜져 있습니다. 끄려면 설정 파일의 `ytmLyrics`를 `false`로 바꿉니다.

## 업데이트

1.6.0부터는 앱이 새 버전을 직접 확인하고 설치합니다.

- 앱을 켜고 30초 뒤와, 그 뒤 하루에 한 번 GitHub의 최신 릴리스를 확인합니다. 새 버전이 있으면 화면에 안내가 잠시 표시되고, 트레이 메뉴의 항목이 **업데이트 설치 (버전)**으로 바뀝니다. 메뉴의 **업데이트 확인**으로 바로 확인할 수도 있습니다.
- 설치는 메뉴에서 **업데이트 설치**를 눌렀을 때만 진행합니다. 게임을 하는 중에 앱이 저절로 다시 시작되지 않습니다.
- 설치할 때는 릴리스 파일을 받아서 GitHub가 함께 알려주는 SHA-256 값과 비교하고, 새 exe의 버전을 확인한 뒤 지금 exe를 바꿔 넣고 다시 실행합니다. 바꿔 넣기 전의 exe는 `PearNowPlaying.exe.old`로 남았다가 다음 실행 때 지워집니다.
- 앱이 직접 받은 파일이므로 "Windows의 PC 보호" 창은 다시 나타나지 않습니다.
- 설치에 실패하면(예: 쓰기 권한이 없는 폴더에 둔 경우) 원래 exe를 그대로 두고 릴리스 페이지를 엽니다. 그때는 직접 받아서 바꿔 주시기 바랍니다.
- 자동 확인을 끄려면 설정 파일의 `checkUpdates`를 `false`로 바꿉니다.

## 설정 파일

설정 파일은 `%AppData%\PearNowPlaying\config.ini`에 있습니다. 트레이 메뉴의 **설정 파일 열기**로 바로 열 수 있으며,
수정한 뒤 **설정 다시 불러오기**를 누르면 변경 사항이 적용됩니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `host`, `port` | `127.0.0.1`, `26538` | Pear Desktop API 서버의 주소입니다. |
| `position` | `BottomLeft` | `TopLeft`, `TopCenter`, `TopRight`, `BottomLeft`, `BottomCenter`, `BottomRight`, `Custom` 중 하나입니다. `Custom`은 끌어서 옮겨 둔 위치입니다. |
| `customX`, `customY`, `customFromBottom` | `40`, `140`, `true` | 끌어서 옮겨 둔 위치입니다. 모니터의 왼쪽 가장자리에서 `customX`(px), 위쪽(`customFromBottom=false`) 또는 아래쪽 가장자리에서 `customY`(px)만큼 떨어져 있습니다. |
| `marginX`, `marginY` | `40`, `140` | 화면 가장자리로부터 떨어진 여백(px)입니다. 다른 UI와 겹치면 이 값을 조정합니다. |
| `scale` | `1.0` | 크기 배율입니다. |
| `panelWidth` | `420` | 곡 카드와 가사 카드의 너비(px)입니다. |
| `monitor` | `0` | 위젯을 표시할 모니터의 번호입니다(0은 주 모니터입니다). |
| `showSeconds` | `6` | 곡이 바뀌었을 때 곡 카드를 표시하는 시간(초)입니다. |
| `opacity` | `0.92` | 배경의 불투명도입니다. |
| `alwaysShow` | `true` | 곡 카드를 계속 표시할지 정합니다. |
| `showOnPause` | `true` | 일시정지하거나 다시 재생할 때도 곡 카드를 잠시 표시할지 정합니다. |

| `showLyrics` | `true` | 가사 카드를 표시할지 정합니다. |
| `lyricsAlbumOnly` | `false` | `true`이면 앨범 곡(공식 음원)에서만 가사를 찾아 표시합니다. |
| `checkUpdates` | `true` | 시작할 때와 하루에 한 번 새 버전이 있는지 GitHub에서 확인합니다. 설치는 메뉴에서 직접 누를 때만 합니다. |
| `lyricsOffsetMs` | `300` | 가사 타이밍 보정값(ms)입니다. 양수이면 가사가 더 빨리, 음수이면 더 늦게 표시됩니다. |

| `ytmLyrics` | `true` | YouTube Music 가사를 먼저 찾을지 정합니다. `false`이면 LRCLIB에서만 찾습니다. 메뉴에는 없는 설정입니다. |
| `ytmLyricsProxy` | `https://ytmbrowseproxy.zvz.be/` | YouTube Music 가사 중계 서버의 주소입니다. |

## 문제 해결

- **게임 위에 위젯이 보이지 않습니다**: 독점 전체 화면 모드는 다른 창이 게임 위에 표시되지 못하게 막는 경우가 있습니다.
  게임 설정에서 화면 모드를 **테두리 없는 창 모드**(borderless / 전체 창 모드)로 바꿔 보시기 바랍니다.
- **트레이 상태가 "Pear Desktop 기다리는 중"으로 표시됩니다**: Pear Desktop이 실행 중이 아니거나, API 서버 플러그인이 꺼져 있는 상태입니다.
  포트를 바꿨다면 설정 파일의 `port`도 같은 값으로 바꿔야 합니다.
- **"단축키를 등록하지 못했어요" 알림이 나타납니다**: 다른 프로그램이 같은 단축키를 사용하고 있습니다. 설정 파일에서 다른 키 조합으로 바꿔 주시기 바랍니다.
- **가사가 표시되지 않습니다**: 트레이 메뉴 맨 위에 있는 가사 상태를 확인합니다.
  - '찾지 못함': YouTube Music과 LRCLIB 모두에 그 곡의 싱크 가사가 없거나, 곡의 제목·아티스트·길이가 가사 데이터베이스에 등록된 정보와 너무 다른 경우입니다. 특히 MV 버전은 공식 음원과 길이가 달라서 가사를 찾지 못하는 경우가 많습니다.
  - '가사 서버에 연결하지 못함': 가사 서버의 응답이 느리거나, 서버가 일시적으로 동작하지 않는 상태입니다. 잠시 뒤에 트레이 메뉴의 **가사 다시 찾기**를 눌러 주시기 바랍니다.
  - `error.log`에는 곡마다 가사를 어떤 방법으로 찾았는지, 또는 왜 찾지 못했는지가 기록됩니다.
- **그 밖의 문제**: 트레이 메뉴의 **오류 기록 열기**를 눌러 `error.log`를 확인해 주시기 바랍니다.

## 통신하는 곳

- 사용자 컴퓨터에서 실행 중인 Pear Desktop API 서버(`127.0.0.1:26538`)
- 앨범 아트 이미지 주소(YouTube Music이 사용하는 Google 이미지 서버)
- YouTube Music 가사(`ytmLyrics=true`일 때):
  - `music.youtube.com`: 지금 곡의 영상 ID를 보내고 가사 ID를 받습니다.
  - `ytmbrowseproxy.zvz.be`: 가사 ID를 보내고 가사를 받습니다. 로그인하지 않은 상태로 YouTube Music에 직접 요청하면 가사를 받을 수 없기 때문에 이 중계 서버를 사용합니다.
    공식 음원은 시간 정보가 있는 가사를 받을 수 있는 경우가 많지만, MV와 개인 업로드 영상은 대부분 받을 수 없습니다.
  - 그래서 MV를 재생할 때는 YouTube Music의 아티스트 페이지에서 같은 제목의 싱글이나 앨범을 찾고, 길이가 같은 **공식 음원**의 가사를 대신 받습니다. 커버곡의 원곡 링크가 MV일 때도 같은 방법을 사용합니다.
    `ytmbrowseproxy.zvz.be`는 Pear Desktop의 YTMusic 가사 제공자가 사용하는 **외부 중계 서버**이며, Google의 공식 서버가 아닙니다.
  - 가사 요청은 YouTube Music 앱(클라이언트 이름 26, 버전 7.01.05)과 같은 형식으로 보냅니다.
  - `www.youtube.com`: 개인이 업로드한 영상(커버 등)에서 가사를 찾지 못했을 때만, 원곡 링크를 찾기 위해 그 영상의 설명란을 읽습니다.
  - 위의 어떤 서버에도 Google 계정 쿠키나 Pear 연결 토큰을 보내지 않습니다.
  - 이 경로들은 공식 API가 아니므로, YouTube나 중계 서버의 사정에 따라 언제든 막힐 수 있습니다. 그러면 자동으로 LRCLIB만 사용합니다.
- 가사 검색: `lrclib.net` (곡 제목, 아티스트, 앨범 이름, 길이만 보냅니다)
- 업데이트(`checkUpdates=true`일 때와 메뉴에서 누를 때): `api.github.com`에서 이 저장소의 최신 릴리스 정보를 받고, 업데이트를 설치할 때 `github.com`(릴리스 파일, GitHub 파일 서버로 넘겨짐)에서 파일을 받습니다. 앱 버전 외의 정보는 보내지 않습니다.

위에 적은 곳 외에는 인터넷에 접속하지 않습니다. Pear 연결 토큰은 `%AppData%\PearNowPlaying\token.txt`에 저장됩니다.

## 빌드

이 프로그램은 C# 7.3, .NET Framework 4.8, WinForms로 만들었으며, 외부 패키지는 사용하지 않습니다.

| 파일 | 내용 |
|---|---|
| `src/PearClient.cs` | Pear API 서버 인증(`POST /auth/{id}`), WebSocket(`/api/v1/ws`) 수신, 재생 제어 |
| `src/OverlayWindow.cs` | 클릭이 통과하는 항상 위 창(`UpdateLayeredWindow`), 페이드와 이동 애니메이션 |
| `src/CardRenderer.cs` | 곡 카드 그리기, 긴 제목 스크롤 |
| `src/LyricsView.cs` | 스크롤되는 가사 목록과 전환 애니메이션 |
| `src/Lyrics.cs` | 가사를 찾는 순서, LRCLIB 검색(Pear와 같은 대조 방식), LRC 파서 |
| `src/YtmLyrics.cs` | YouTube Music 가사(Pear의 YTMusic 가사 제공자와 같은 방식), 공식 음원 찾기, 영상 설명란 읽기 |
| `src/CoverLyrics.cs` | 커버곡 설명란에서 원곡 링크 고르기, 편곡·리믹스 걸러내기 |
| `src/Theme.cs` | carol-web 색 토큰, Pretendard JP 로딩과 글리프 커버리지 확인 |
| `src/TrayApp.cs`, `src/Hotkeys.cs`, `src/Config.cs` | 트레이 메뉴, 전역 단축키, 설정 |

- **Windows**: [.NET SDK](https://dotnet.microsoft.com/download)를 설치한 뒤 `dotnet build -c Release`를 실행합니다. Visual Studio에서 `PearNowPlaying.csproj`를 열어 빌드할 수도 있습니다.
- **Linux**: `build.sh`가 dotnet SDK의 Roslyn 컴파일러와 Mono의 .NET Framework 참조 어셈블리를 사용해 `bin/PearNowPlaying.exe`를 만듭니다.
- **macOS 버전**: [macOS 안내](macos/README.md)를 참고합니다.
